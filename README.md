# Python Maze Converter 

**Course:** Introduction to Software Engineering (Curtin University)

## Overview
This repository contains a Python application designed to process and convert maze data. The project emphasizes software engineering best practices, including modularity, version control branching, and unit testing.

## Files Included
* `maze_converter.py`: The core logic and main application script.
* `test_maze_converter.py`: Unit tests verifying the converter's logic.
* `test_maze.txt` & `maze_output.txt`: Sample input and output data files.
* `Documentation_SE_assignment.odt`: Detailed assignment documentation and engineering design.

## Technical Skills Demonstrated
* **Language:** Python 3
* **Concepts:** Test-Driven Development (TDD), file I/O operations, modular design.
* **Version Control:** Feature branching (`modularity_implementation`, `test_implementation`) and merging.

## How to Run
1. Run the converter: `python3 maze_converter.py`
2. Run the tests: `python3 -m unittest test_maze_converter.py`
